# GetSitter 👶🛡️

**"גט-טקסי" של בייביסיטר** — אפליקציה שמחברת הורים לשמרטפים מאומתים בקרבת מקום, בלחיצת כפתור.

פרויקט עצמאי לחלוטין. אין לו שום קשר תוכני לשאר התוכן במאגר — הוא יושב בתיקייה נפרדת (`getsitter/`) עם קוד נפרד.

## הרעיון
כמו להזמין מונית, רק שבמקום נסיעה מקבלים שמרטף/ית. הדגש המרכזי הוא **בטיחות הילדים**:

- 🔎 בדיקת רקע פלילי מקיפה
- 📜 תעודת יושר ממשטרת ישראל (תנאי סף מוחלט)
- 🪪 אימות זהות ביומטרי
- 🎙️ ראיון אישי + הכשרת עזרה ראשונה
- 📍 מעקב חי במפה ושיתוף מיקום עם איש קשר לחירום
- 🆘 כפתור מצוקה (SOS) ותמיכה 24/7
- ⭐ דירוגים מאומתים בלבד (רק מי שהזמין בפועל)
- 🛡️ ביטוח אחריות על כל הזמנה
- 🔁 בדיקות רקע מתחדשות מדי שנה

## מה כולל אב-הטיפוס
אתר/אפליקציה חד-עמודי (HTML/CSS/JS, ללא תלות בשרת) עם:
- מסך נחיתה + ווידג'ט חיפוש שמרטפים לפי עיר ותאריך
- רשת שמרטפים מסוננת לפי טווחי גיל / התמחות
- כרטיס פרופיל מלא + תהליך הזמנה עם חישוב עלות
- **אשף הרשמה לשמרטף/ית** רב-שלבי עם ולידציה, הסכמות בטיחות והעלאת תעודת יושר
- מקטעי בטיחות, "איך זה עובד", ביקורות, שאלות נפוצות

> ⚠️ נתוני הדגמה בלבד. לא מתבצעות בדיקות רקע אמיתיות ואין שמירת נתונים אמיתית — זהו אב-טיפוס להמחשת הקונספט והחוויה.

## הרצה מקומית
פשוט לפתוח את `index.html` בדפדפן, או:
```bash
cd getsitter
python3 -m http.server 8000
# פתחו http://localhost:8000
```

## מבנה
```
getsitter/
├── index.html   # מבנה הדף והתוכן
├── styles.css   # עיצוב (RTL, מותג GetSitter)
├── app.js       # לוגיקה: חיפוש, פרופילים, הזמנה, אשף הרשמה
└── README.md
```

## הצעדים הבאים (להפיכה למוצר אמיתי)
- Backend + DB (משתמשים, שמרטפים, הזמנות, דירוגים)
- אינטגרציית בדיקות רקע ותעודת יושר מול ספק מוסמך
- אימות זהות (KYC), תשלומים, התראות, מפה חיה (GPS)
- אפליקציות נייטיב (iOS/Android)
