# מקורות מכרזים — מחקר ואימות

עודכן: יוני 2026. הכתובות אומתו דרך חיפוש אינטרנט. **יש לאמת שוב בזמן ריצה**
מהמחשב שלך — חלק מהאתרים חוסמים גישה מבחוץ (geo) או משתנים מעת לעת.

## הערות חשובות

- **`yefenof` — מועמד מצוין למתאם השני.** המבנה נקי ועקבי: עמוד מכרז בכתובת
  `yefenof.co.il/Tender?tenderID=NNNN`, וקבצים תחת `/Uploads/tenderDocuments/`.
  קל לפענוח ויעזור לאמת את התשתית הגנרית מול אתר שני שונה מ-iroads.

- **`iec` (חברת החשמל)** עלול להיות חסום לגישה מחוץ לישראל. ממחשב בישראל זה
  אמור לעבוד. אם נחסם — המתאם ידלג בצורה נקייה ויסמן בלוג.

- **`mekorot` ותאגידי מים** — נפוצות חוברות בתשלום. המתאם יוריד את החומר
  החינמי (הודעה/תנאי סף) ויסמן `paid`/`partial`. רבים מהמכרזים מתפרסמים כ-PDF
  הודעה בודד ולא כעמוד מובנה.

- **`mrgov`** — לפי המחקר ניתן להוריד מסמכים חינם לאחר הרשמה; ייתכן שדפדוף
  בסיסי אפשרי גם בלי התחברות. לבדוק בזמן מימוש; בינתיים מוגדר `requires_login`.

- **אגרגטורים בתשלום שלא נשתמש בהם:** GOVO, Wizbiz, יפעת, dekel, tenders.co.il —
  הופיעו בחיפושים אך הם בתשלום/מנוי ולכן מחוץ לתחום (משתמשים רק במקורות
  ישירים + jobiz החינמי).

- **תאגידי מים אזוריים** מבוזרים מאוד (עשרות אתרים נפרדים: מי אביבים, מניב
  ראשון, מי שיקמה, מי רמת גן ועוד). מומלץ בעתיד מתאם גנרי יחיד מבוסס-config
  שמקבל רשימת תאגידים, במקום מתאם נפרד לכל אחד.
