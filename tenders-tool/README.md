# כלי סריקה והורדה של מכרזי תשתיות בישראל

כלי שמריצים **ידנית מהמחשב**: מאתר **מכרזי קבלנים פתוחים בתחום התשתיות**
(כבישים, גשרים, מסילות, מים וביוב, ניקוז, חשמל, גז, נמלים, רק"ל ועוד),
מוריד את **כל מסמכי המכרז**, ומתייק אותם בצורה לוגית. בנוסף נבנים אינדקס
מרכזי (`_index.csv`) ודוח נוח לצפייה (`report.html`).

> הכלי **לא** קורא ולא מנתח את תוכן המסמכים — רק מוריד ומתייק. כל הסיווג
> מתבצע מתוך כותרות/קטגוריות בעמודי הרשימה, לא מתוך ה-PDF.

---

## התקנה (Windows)

נדרש Python 3.11 ומעלה.

```bat
cd tenders-tool
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
```

(ב-macOS/Linux: `python3 -m venv .venv && source .venv/bin/activate` ואז אותו הדבר.)

### אישורי גישה למקורות עם הרשמה

חלק מהמקורות דורשים התחברות (חינם). העתק את קובץ הדוגמה ומלא פרטים:

```bat
copy .env.example .env
```

ערוך את `.env`. כרגע הרלוונטי הוא **מינהל הרכש הממשלתי**:

- היכנס ל-<https://mr.gov.il/ilgstorefront/he/>, הירשם (הרשמה חינם), ומלא ב-`.env`:
  ```
  MRGOV_USERNAME=המשתמש_שלך
  MRGOV_PASSWORD=הסיסמה_שלך
  ```

מקור שאין לו פרטים ב-`.env` פשוט יידלג בצורה נקייה (לא יפיל את הסריקה).
קובץ `.env` **לא נכנס ל-git** (ראה `.gitignore`).

## הרצה

```bat
python scan.py --all                 :: סריקת כל המקורות הפעילים
python scan.py --source iroads       :: סריקת מקור בודד
python scan.py --list-sources        :: רשימת המקורות והסטטוס שלהם
python scan.py --all --dry-run        :: הצגה בלבד — מה היה יורד, בלי הורדה
```

בסיום מודפס סיכום בטרמינל, ונוצרים `tenders/_index.csv` ו-`tenders/report.html`.
פתח את `report.html` בדפדפן (נוח גם בנייד).

## מבנה הפלט

```
tenders/
  <מפרסם>/
    <YYYY-MM-DD מועד הגשה>__<מספר מכרז>__<כותרת מקוצרת>/
      v1_<תאריך>/        ← ההורדה הראשונה (כל הקבצים)
      v2_<תאריך>/        ← עדכון (נספח / דחיית מועד) — גרסה חדשה, לא דורסים
      meta.json          ← מטא-דאטה + היסטוריית גרסאות
  _archive/<מפרסם>/...   ← מכרזים שמועדם עבר (עוברים אוטומטית; לא נמחקים)
  _index.csv             ← אינדקס מכרזים פתוחים בלבד (נפתח ב-Excel)
  report.html            ← דוח לצפייה (ממוין לפי מועד הגשה, מדגיש חדשים/מתקרבים)
  _state.json            ← מצב פנימי (זיהוי "חדש מאז הרצה קודמת")
  _logs/                 ← לוג מפורט לכל סריקה
```

### התנהגות

- **מכרזים פתוחים בלבד** — מכרז שמועד ההגשה שלו עבר מוחרג ומועבר ל-`_archive/`.
- **אידמפוטנטי** — מכרז שכבר ירד ולא השתנה לא יורד שוב (הרצה חוזרת מהירה).
- **גרסאות** — אם התווסף נספח/השתנה סט הקבצים, נוצרת תת-תיקיית גרסה חדשה
  (`v2_...`) ולא דורסים את הישנה.
- **איחוד כפילויות** — אותו מכרז מכמה מקורות מאוחד לתיקייה אחת; המקור הישיר
  (אתר המפרסם) מנצח כמקור הורדה, וכל המקורות נשמרים בעמודת `מקורות`.
- **מכרזים בתשלום** — אם חוברת המכרז בתשלום, מורידים רק את החינמי ומסמנים
  סטטוס `paid`/`partial`. הכלי לא מנסה לשלם.
- **חסימות/CAPTCHA** — מקור שחוסם אוטומציה מדולג בצורה נקייה ומסומן בלוג
  ובדוח; אין ניסיון לעקוף.
- **התנהגות מנומסת** — השהיות בין בקשות וכיבוד `robots.txt`.

## כוונון

- **מילות מפתח:** `config/keywords.yaml` — רשימות הכללה (תשתיות), חיזוק (ביצוע)
  והחרגה (רעש). ערוך בלי לגעת בקוד. מכרז עם מילת תשתית בלבד מסומן
  `match_confidence=low` כדי שתעבור עליו ידנית.
- **מקורות:** `config/sources.yaml` — הפעלה/כיבוי מקורות וכתובות.

## הוספת מקור חדש (ארכיטקטורת מתאמים)

כל מקור הוא **מתאם (adapter)** עם ממשק אחיד. הוספת מקור = הוספת מתאם בלבד,
בלי לגעת בליבה:

1. צור `infra_tenders/adapters/<name>.py` עם מחלקה היורשת מ-`BaseAdapter`
   ומממשת `fetch_open_tenders(self, page, client) -> list[Tender]`.
2. רשום אותה ב-`infra_tenders/adapters/__init__.py` (במילון `ADAPTERS`).
3. הוסף רשומה ב-`config/sources.yaml` (עם `enabled: true`).

המתאם אחראי רק על *גילוי* המכרסים והקבצים. הליבה מטפלת בפילטור, איחוד
כפילויות, גרסאות, ארכוב, הורדה, אינדקס ודוח.

## בדיקות

```bat
python -m pytest -q
```

הבדיקות מאמתות פענוח תאריכים, סיווג מילות מפתח, פענוח HTML של נתיבי ישראל
(על קבצי דוגמה שמורים ב-`tests/fixtures/`), איחוד כפילויות, וכל מסלול
התיוק/הגרסאות/הארכוב — בלי תלות ברשת.

> **הערה על מתאם נתיבי ישראל:** המתאם נכתב בצורה הגנתית (סלקטורים גנריים
> לטבלאות/כרטיסים). בהרצה הראשונה האמיתית, אם לא נמצאו מכרזים, פתח את עמוד
> המכרזים בדפדפן ובדוק את מבנה ה-HTML (F12), והתאם את `SELECTORS` בראש
> `infra_tenders/adapters/iroads.py`. הרץ `--dry-run` כדי לבדוק בלי להוריד.

## תזמון אוטומטי (Windows Task Scheduler) — לעתיד

הכלי ידני בכוונה. אם בעתיד תרצה הרצה מתוזמנת:

1. צור קובץ `run.bat` בתיקיית הפרויקט:
   ```bat
   @echo off
   cd /d "%~dp0"
   call .venv\Scripts\activate
   python scan.py --all >> tenders\_logs\scheduled.log 2>&1
   ```
2. פתח **Task Scheduler** → **Create Basic Task**.
3. בחר תדירות (למשל יומי בבוקר), ובשלב **Action** בחר **Start a program**
   והצבע על `run.bat`.

(אין צורך בכך כעת — מומלץ להריץ ידנית עד שהמקורות מכווננים.)
